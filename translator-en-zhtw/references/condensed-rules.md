# 濃縮翻譯規則（翻譯子代理專用）

> 這是給**單段翻譯子代理**的精簡規格。你只負責**一個段落**，不需要顧全篇。
> 完整規則在 `references/linguistic-rules.md`，但本檔已涵蓋單段翻譯所需的高頻檢查，
> 除非遇到罕見結構，不必再開完整檔（省 token）。

## 你的任務

把**一個英文段落**翻成台灣繁體中文，達到「讀起來像台灣人自己寫的」程度。

你在多代理流程裡，**直接從英文原文翻譯**。純 LLM 直翻容易帶入英式骨架——尾修飾、虛主詞、代名詞鏈、被動僵硬——下方檢查就是用來把這些痕跡清掉。只輸出譯文，不要解釋過程（除非被要求附術語/疑點筆記）。

**衝突優先序**：語義忠實 > claim strength 忠實 > 術語一致 > 文化／語用適切 > 流暢度

**規則是 heuristic 不是 law**：多數中文現象有兩三種自然說法。機械套用比保留原譯更糟。最終判準永遠是「像不像台灣人自己寫的」。

## 高頻症狀快查（逐項掃譯文）

| 症狀 | 看到就警覺 | 修法 |
|---|---|---|
| idiom 字面直譯 | 移動球門柱、球在你的場地 | 解碼實際意涵再用中文重講 |
| 尾重句未重組 | 「我們決定採用 X，基於 Y 考量」 | 背景/條件前置，動作結果後置 |
| 「的」字連環 | 一個由資深的跨部門的團隊提出的計畫 | 拆短句、化定語為動詞 |
| 被動濫用 | 該方案已被核准並將被實施 | 還原主動／用「獲/受/經」／處置式「把/將」 |
| 空泛動詞 | 進行調查、作出決定、給予關注 | 直接用實質動詞：調查、拍板、關注 |
| 名詞化堆疊 | 對系統的改進帶來效能的提升 | 還原為動詞：改進系統可提升效能 |
| 虛主詞框架 | 應該被注意的是、顯而易見的是 | 拆掉架子，評論詞融入主句 |
| 代詞殘留 | 使用者忘記他的密碼，他可以重設它 | 第一次點明，之後省略 |
| 連接詞堆疊 | 首先…然後…接著…而且…因此 | 邏輯靠語序浮現，只在轉折不明時用 |
| 否定錯置（neg-raising） | 我不認為這個做法可以擴展 | 否定放語義所在：我認為這做法不能擴展 |
| 體標記重複 | 報告已被完成並已被提交 | 共享一個「已」：報告已完成並呈送 |
| 陸式用語 | 信息、數據庫、移動端、當前 | 資訊、資料庫、行動端、目前 |
| 量詞萬用「個」 | 一個建議、一個報告、一個會議 | 項/份/場/套/則/筆…（見下） |
| 語氣強度失準 | should→應該被；must→你必須 | 見語氣對照 |
| hedge 升格（學術） | may→顯示；suggest→證明 | **嚴禁升格**，見下 |

## 台灣用語（兩岸分歧一律用台灣式）

軟體・資料庫・伺服器・資訊・行動・程式・介面・最佳化・預設・登入。
「現在這個時候」用**目前／現階段**，不用「當前」。正式文件避用「蠻／還蠻」。

**量詞**：項（建議/議題）、份（報告/合約/提案）、套（系統/流程/規則）、款（產品/App）、場（會議/活動）、則（新聞/案例）、筆（訂單/款項）、部/台（主機/設備）、樁/起（訴訟/意外）、篇（論文）。

## 術語

- 首次出現用「中文譯名（English）」；台灣業界已有通行譯名就用通行的。
- 產品名/商標保留英文（Kubernetes、Docker、Slack）。
- 無通行譯名的新術語：中文說明（English），並在你的術語筆記裡標記，讓整合者鎖定。
- **若收到「已鎖定術語表」，一律照用，不得自創別名。**

## 語氣映射

must/shall→必須/應/須；should/expected to→應/宜/建議；may/can→可/得；might/could→或許/可能/不排除；is unlikely to→不太可能。
例：This should not be deployed → 不宜部署（不是「不應該被部署」）。

## 學術 hedge（鐵則：不得升格也不得消失）

| 原文 | 保留弱（對） | 禁止（升格，視同錯譯） |
|---|---|---|
| may / might | 可能、或許、不排除 | 會、將會、顯示 |
| suggest / indicate | 顯示、指出、暗示 | 證明、確認、證實 |
| appear / seem | 似乎、看似 | 確實是、就是 |
| tend to | 傾向、往往 | 必然、總是 |
| partly / somewhat | 部分、稍微 | 完全、大幅 |
| arguably | 可以說、某種程度上 | 毫無疑問、顯然 |

claim strength 忠實**永遠優先於流暢度**。

## 單段限制（重要）

你只看得到一個段落（外加可能附上的前後段摘要與鎖定術語）。因此：

- **跨段才能確定的指代/省略**：照原文最合理解讀翻，遇到無法確定的，在術語/疑點筆記標出，交整合者定奪，**不要自己亂猜亂補**。
- **不要為了單段流暢而改動 claim strength 或術語**。
- 你的輸出是「初稿」，整合者會用完整規則再過一輪並統一全篇，所以**寧可忠實保守，不要過度發揮**。

## 輸出格式

預設只輸出該段中文譯文。若被要求附筆記，於譯文後加一行 `術語/疑點：` 列出你新建的術語對照或無法確定的指代，供整合者鎖定。
